# Stage 6: Repair vs Replace Decision Engine

This module represents the final layer of the AutoInspect AI core pipeline. It evaluates the unified data generated by Stage 5 (Part, Damage, Severity, and Confidences) and uses a configurable rule-based engine to recommend `repair`, `replace`, or `inspect`.

## Architecture
- `configs/decision_rules.yaml`: The master matrix that holds all rules. Parts are grouped into logical categories (Body Panels, Glass, Lights/Mirrors, Tires) for easy maintenance.
- `src/decision_engine.py`: Loads the YAML config, enforces confidence threshold safety checks, evaluates the inputs top-down, and returns a recommendation alongside a human-readable reason.

## Safety Principles
- The Decision Engine **does not** guarantee mechanical safety. Every output includes a disclaimer that professional inspection is recommended/required.
- Low-confidence detections from ANY upstream model immediately abort the specific rules and default to a conservative `inspect` recommendation.
- Safety-critical parts (windshields, tires, headlights) are mapped conservatively (e.g., shattered glass is always `replace` regardless of the ML severity score).
